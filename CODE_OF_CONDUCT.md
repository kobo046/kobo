# Code of Conduct

## Our pledge

We pledge to make participation in this project a welcoming and harassment-free experience for everyone, regardless of experience level, identity, background, or ability.

## Expected behavior

- Be respectful and constructive.
- Discuss ideas and code, not personal characteristics.
- Give useful context when reporting a problem.
- Accept feedback gracefully and focus on the shared goal.
- Protect the privacy of players and contributors.

## Unacceptable behavior

- Harassment, threats, discrimination, or personal attacks.
- Publishing another person's private information without permission.
- Deliberately disrupting discussions or project infrastructure.
- Using project access to inspect or modify data without authorization.

## Enforcement

Report conduct concerns privately to the maintainer through the GitHub profile. The maintainer may edit or remove contributions and may temporarily or permanently restrict participation when behavior is inappropriate, threatening, or harmful.

## Scope

This policy applies in repository discussions, code review, project communication, and public spaces where someone represents this project.
